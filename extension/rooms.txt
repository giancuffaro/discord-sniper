# rooms.txt — THE ONE LIST of every room we have ever been to, and whether
# it is ON right now. This file is the whole answer to "why is X trading"
# or "why didn't X open a tab": a room that is `on` opens a tab, is read,
# and TRADES LIVE; a room that is `off` does none of that. There is no
# separate testing switch any more (G, 9/9: "if I selected to open it I
# obviously want it live"). Nothing else — not the extension, not the popup,
# not START HERE.bat — keeps its own copy of this list.
#
# Format, one room per line, pipe-separated:
#   channel_id|full_url|label|group|state
# state = on | off | lapsed
#   on      opens a tab, reads, trades live
#   off     benched by G — no tab, nothing read, nothing traded (the reason
#           sits in the comment line above it, never deleted)
#   lapsed  the subscription ran out — same as off, but the extension knocks
#           on its door once a day (off-hours) and tells you when it is
#           readable again; flipping it on is still your click
# Lines starting with # are comments. Blank lines are ignored.
# Whop rooms use their canonical "whop:xxx" id in the first field — that's
# what background.js's whopRoomOf() matches on.
#
# HOW TO FLIP A ROOM: the popup's Channels tab — one switch per room. The
# switch writes THIS file through the bridge (POST /rooms) and the extension
# re-reads it on the spot: ON opens the tab and starts trading it, OFF
# closes the tab and stops. Editing the 5th field by hand works too (the
# extension picks it up within a minute). Closing a tab by hand is NOT a
# bench any more — START HERE reopens every `on` room; use the switch.
#
# History of every cut and re-add lives in HANDOFF-LOG.md; this file keeps
# only the one-line reason above each benched room.
