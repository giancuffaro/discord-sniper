HOW TO FILL THE CLAUDE PROJECT (2 minutes)
==========================================
1. INSTRUCTIONS box  -> paste the whole of PROJECT-INSTRUCTIONS.md
2. CONTEXT           -> upload every file in the context/ folder
                        (HANDOFF snapshot, broker reference, ratchet study,
                         methodology, option-data plan, Market Sniper
                         handoff, pitches, room list)
3. SCHEDULED         -> the daily journal already runs in Cowork
                        (daily-journal-and-fix, weekdays 16:45). Nothing
                        to add here unless you want a second reminder.
4. MEMORY            -> fills itself after a few chats.

Keep in mind: the HANDOFF snapshot goes stale the moment a rule changes.
The Instructions tell Claude the live file in the folder always wins.
Re-upload the snapshot every week or two (copy HANDOFF.md over it).
